# Task 4 - Classification with Logistic Regression

## Objective
Build a binary classification model using Logistic Regression.

## Dataset
Breast Cancer Wisconsin Dataset from Scikit-learn.

## Tools Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Steps Performed
1. Loaded the Breast Cancer dataset
2. Performed train-test split
3. Standardized features using StandardScaler
4. Trained Logistic Regression model
5. Generated predictions and probabilities
6. Evaluated the model using:
   - Accuracy
   - Precision
   - Recall
   - Confusion Matrix
   - ROC-AUC
7. Visualized ROC curve
8. Visualized sigmoid function
9. Tested different classification thresholds

## Conclusion
Logistic Regression was successfully used for binary classification. The model was evaluated using multiple classification metrics, and threshold tuning was performed to understand the trade-off between precision and recall.
